# claude-office：できること・嬉しいこと

Claude Code のセッションを、ドット絵のオフィスに並べて見る手元のツール。何本もの Claude Code セッションにそれぞれ役割を与えて、作業を分けて明確に、効率よく進めたい人向け。席を外して戻っても、どのセッションが作業中で、どれが自分の返事を待っているかが一目で分かる。

**解く問題**：セッションを立ち上げまくると、コンテキストもタスクの進み具合もセッションの数だけ散らばり、効率が落ちる。claude-office はその考えとコンテキストの状態を1画面に見える化する。重いコンテキストのまま続けない・放置に気づいて閉じる、が自然にできるので、トークン消費の節約にもつながる。

## できること

### 見る

| 機能 | 中身 |
|---|---|
| セッションをキャラで並べる | 動いている Claude Code の全セッションを、ドット絵のキャラとしてオフィスに座らせる |
| 4つの状態 | 作業中（タイピング）／あなたの番（返事が来た・許可などの確認待ち。手を挙げて跳ねる）／放置（返事から30分。居眠り）／閉じた（空いた椅子。1時間で消える） |
| 島（事業・プロジェクトごとの席） | `claude -n 島の呼び名@係名` で起動すると、その島に座る。名札は係名だけ |
| ホワイトボード | 「あなたの番」の人を、待たせている長い順に並べる。最後の返事の1行目つき。10分を超えたらオレンジ |
| 吹き出し | 作業中の時間、返事の書き出し2行、確認待ち、放置の時間 |
| コンテキストのゲージ | 名札の下に使用率。60%で黄、80%で赤と「そろそろ /compact」 |
| 使用量の掲示板 | 壁に5時間・1週間の枠の使用率と、リセットまでの時間 |
| 今日の日報 | 壁の黒板に、今日セッションが動いた時間（のべ）・指示の回数・島ごとの横棒。島の看板にも「今日 4時間35分」 |
| 気づかせる仕組み | 待ちがいれば画面上にオレンジの帯。ブラウザのタブにも「(3)」と待ち人数 |

### さわる

| 機能 | 中身 |
|---|---|
| カード | キャラを押すと、作業フォルダ・最後の返事の数行・コンテキストのトークン数が出る |
| セッション名のコピー | ターミナルのタブを探す手がかりにする |
| 再開のコマンド | 閉じた人なら `claude --resume …` をコピーできる。「退出させる」で空席も消せる |
| 島を作る・直す・消す | 画面から操作できる。色はターミナルのタブ色の6色 |
| 日報を大きく開く | 黒板を押すと、いちばん時間を使った島・島ごとの1日の帯・よく動いたセッションが出る。カードにもそのセッションの今日の時間と帯 |
| 作った直後に座らせる | 作った島の起動コマンドが出て、係名を打ってコピーできる（Enter でも）。打っている間は消えず、コピーしたら欄が空になるので、続けてもうひとり分も打てる |
| ドラッグで島へ移す | キャラを島へ落とすと `/rename 島の呼び名@係名` が出てコピーできる（係名は今の名前から入れておく）。タブで打つまで落とした島に「移り待ち」で座り、移ったら知らせる。5分打たれなければ元に戻る。「＋ 島を作る」へ落とすと、島を作ってからそのまま移せる |
| 拡大縮小と「全体」 | 全部の島を1画面に収める。島は画面の幅に合わせて詰めて並ぶ |
| ダークモード | 部屋だけ暗くして、人と名札は明るいまま |

### ターミナル側

| 機能 | 中身 |
|---|---|
| ステータスライン | 各セッションの一番下に「セッション名 · ctx ███████░░░ 72%」 |

### 入れ方・動き方

| 機能 | 中身 |
|---|---|
| 実行ファイル1つ | Go の標準ライブラリだけで、外部ライブラリなし。`claude-office install` で自動起動（macOS は launchd、Linux は systemd、Windows はスタートアップフォルダ） |
| ステータスラインの登録 | `claude-office statusline install`。元の設定は `.bak` に残す。別のステータスラインを置き換えたら、uninstall で元に戻す |
| 見本の画面 | `claude-office serve -demo` で、Claude Code がなくても見た目を確かめられる |

## 何が嬉しいか

1. **離席から戻って5秒で、どこから手をつけるか分かる。** オレンジの人とホワイトボードの一番上から返せばよい。ターミナルのタブを1つずつ開いて回らなくて済む。
2. **待たせすぎに気づける。** 待ち時間の長い順に並び、10分を超えると色が変わる。返事が埋もれて Claude が止まったままになるのを防げる。
3. **許可の確認待ちを見逃さない。** 返事が終わった人と同じく「あなたの番」に出る。
4. **コンテキストが重くなる前に手を打てる。** 80%で赤くなるので、`/compact` や会話の切り替えを早めにできる。性能が落ちた状態で作業し続けずに済む。
5. **使用量の上限に先回りできる。** 5時間・週の枠と、リセットまでの時間が常に見える。重い作業をいつ回すか決めやすい。
6. **事業ごとに頭を切り替えやすい。** 島＝事業なので、「アプリ開発は今3つのセッションが動いていて、ブログは全部放置」と、事業の進み具合も一緒に見える。
7. **今の使い方を変えずに済む。** 指示はこれまでどおりターミナルから出す。画面は見るだけなので、操作を覚え直す必要がない。
8. **お金がかからず、外に出ない。** Claude を呼ばないのでトークンは0。データは手元だけで、外へ何も送らない。
9. **閉じた会話にすぐ戻れる。** 再開のコマンドをコピーするだけ。会話の ID を探さなくて済む。
10. **今日がんばった分が見える。** 1日の終わりに「のべ何時間動いたか」「どの島に時間を使ったか」が分かる。事業ごとの時間の配分を振り返れる。
11. **眺めていて楽しい。** ドット絵のキャラがタイピングしたり居眠りしたりするので、開きっぱなしにしたくなる。

## 他と違いそうな点（比べるときの目安）

- **見るだけで、Claude を呼ばない。** トークン0で、セッションの外側から読むだけ。
- **事業・プロジェクトの単位でまとめる。** 係名の決まり（`島の呼び名@係名`）で、自動で島に振り分ける。
- **「待たせている」ことを軸にした表示。** あなたの番・待ち時間の順・確認待ち。
- **コンテキストの使用率と使用量の枠を、全セッションまとめて1画面に出す。**
- **Gather のようなドット絵のオフィス。** 状態がキャラの動きで分かる。
